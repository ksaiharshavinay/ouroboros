## Why Apache 2.0?

Apache 2.0 was chosen because Section 3 includes an **explicit patent grant**:

> Each Contributor hereby grants to You a perpetual, worldwide, non-exclusive,
> no-charge, royalty-free, irrevocable (except as stated in this section)
> patent license to make, have made, use, offer to sell, sell, import, and
> otherwise transfer the Work...

This means that once the patent is granted and this project is open-sourced,
all users of the software automatically receive a royalty-free license to the
patented recursive feedback mechanism for use within this software.

This is intentional — the patent protects the invention from third-party
exploitation, while Apache 2.0 ensures the open-source community can use
OUROBOROS freely.
